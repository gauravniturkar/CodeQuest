# CodeQuest — Learn Python, gamified

An AI-powered practice platform for Python fundamentals. Seven sections, fresh
questions generated by Claude on every run, XP and streaks, a leaderboard, and a
full theme system with true light/dark modes plus five accent palettes.

![Built with Claude](https://img.shields.io/badge/built%20with-Claude%20AI-orange) ![License](https://img.shields.io/badge/license-MIT-blue)

## Stack

- **Vite + TypeScript** (strict), no UI framework — the DOM work is small enough
  that a framework would cost more than it saves
- **Multi-page build** — `index.html` (marketing) and `game.html` (the app) are
  separate entry points, so deep links keep working
- **Vercel serverless functions** in `api/` for question generation and hints

## Getting started

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build to dist/
npm run preview    # serve the built output
```

`npm run build` runs `tsc --noEmit` first, so a type error fails the build.

```
  generate.js         # Claude question generation

```

## Theming

Two independent axes, both stamped on `<html>` and restored before first paint
so there is no flash:

| Attribute | Values |
|---|---|
| `data-mode` | `light`, `dark` (a `system` preference resolves to one of these) |
| `data-accent` | `citrus`, `ember`, `ocean`, `violet`, `mono` |

Accents are derived from a hue/saturation pair, with lightness retuned per mode,
so every shade stays in relationship and contrast holds in both modes. `mono` is
a zero-saturation palette — a genuine black-and-white theme.

To add an accent, add one line to `tokens.css` and one entry to `ACCENTS` in
`src/lib/theme.ts`:

```css
[data-accent='rose'] { --accent-h: 340; --accent-s: 80%; }
```

## Keyboard

| Key | Action |
|---|---|
| `⌘K` / `Ctrl+K` | Command palette |
| `A`–`D` or `1`–`4` | Answer a multiple-choice question |
| `↵` | Continue to the next step |
| `⇧D` | Toggle light / dark |
| `Esc` | Close palette or popover |

## AI questions

`startSection` calls `/api/generate`. If the endpoint is unreachable — no API
key, local dev without `vercel dev`, a network failure — the built-in bank in
`src/data/fallback.ts` takes over and a toast says so. Practice never dead-ends.

Run the functions locally with `vercel dev` instead of `npm run dev` if you want
live generation.

## Progress and the leaderboard

Progress (XP, streaks, per-section bests, name) is stored in `localStorage` under
`cq.progress`. Scores go through `src/lib/storage.ts`, which writes to the Claude
artifact host's `window.storage` when present and falls back to `localStorage`
everywhere else.

The board is seeded with five pace-setter entries so it isn't empty on a fresh
install. They are flagged `bot: true` and rendered with a `BOT` label — they are
never presented as real players.

## Accessibility

- Every animation is gated behind `prefers-reduced-motion`
- Focus rings are visible and theme-aware
- Locked sections are real `disabled` buttons with descriptive labels
- Live regions announce hints, toasts and combo events
